## Nota sobre datos personales

Este repositorio es público. El `SIAE` y el `Comprobante` contienen número de cuenta, nombre completo
y calificaciones. **Antes de subirlos hay que decidir una de dos:**

1. **Tacharlos** (número de cuenta y cualquier dato de identificación) antes de subir.
2. **No subirlos** y transcribir a mano solo lo necesario —clave de asignatura, nombre, calificación,
   intentos— a una tabla dentro del repositorio. Es lo que la calculadora de promedio necesita, y no
   requiere el documento original.

La segunda opción es la recomendada. Un kárdex completo en un repositorio público es un dato que no se
puede retirar después: git conserva el historial aunque el archivo se borre.
